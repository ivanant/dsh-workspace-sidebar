# dsh-workspace-sidebar

中文 | [English](README.en.md)

让 DSH Web GUI 的**右侧栏**按工作区共享：同一个工作区里的所有对话使用同一份右侧栏标签与布局；切换到同工作区的另一个对话时，右侧栏内容不再跟着换。

## 功能

- 在「设置 → 通用」新增一个开关「按工作区共享侧边栏」，默认**开启**；开关下方会显示当前状态（例如「已生效：右侧栏跟随该工作区的第一个会话」）。
- 工作区模式：每个工作区用**第一个会话**（工作区会话列表里的第一项，跳过已归档项）作为右侧栏的承载会话；该工作区所有对话共用这份侧栏（已打开标签、激活标签、分屏、浮动面板、展开状态等）。
- 对话模式：关闭开关后，恢复 DSH 自带的按会话保存行为。
- 工作区切换：换到另一个工作区时，右侧栏切换到该工作区第一个会话的那份布局。
- 第一个会话被归档/删除后，自动顺延到下一个可用会话。
- 没有工作区的对话（Ungrouped）没有共享范围，仍跟随当前对话。

## 安装

```powershell
dsh plugin --profile web add dsh-workspace-sidebar
```

或在 Web 界面「设置 → 插件」里从本地目录安装。安装后刷新页面，在「设置 → 通用」里可以看到开关。

## 实现方式

- **不替换、不修改**官方 `ui-sidebar-right` 的 `rightbar` 槽，也不 fork 官方包，因此官方后续更新可以正常升级。
- 插件只做两件事：
  1. 注册「设置 → 通用」里的一行开关。
  2. 在切换会话/工作区时，让官方右侧栏选中该工作区的第一个会话：临时把当前会话源映射到第一个会话，并同步通知官方 `SidebarSessionViews` 重新选择，然后立即恢复。这样官方右侧栏的根组件、标签、持久化和导航都保持原样。
- 开关状态存在浏览器 `localStorage` 的 `dsh.workspace-sidebar.v1.mode`。

## 验证

- 刷新后打开「设置 → 通用」，能看到「按工作区共享侧边栏」和状态行。
- 状态行显示「已生效：右侧栏跟随该工作区的第一个会话」。
- 打开右侧栏，切到同一工作区的另一个对话，右侧栏标签与布局保持不变。
- 关闭开关后，再切换对话，右侧栏恢复为每个对话各自保存。

## 边界

- 右侧栏布局仍保存在浏览器 `localStorage`，不跨设备同步。
- 工作区模式下，右侧栏里的**会话内容类**标签（例如「对话」标签）绑定的是该工作区的第一个会话，而不是当前正在看的会话。文件、文档预览、终端等以工作区目录为根的内容不受影响。
- 第一个会话由工作区列表的顺序决定；在侧栏里拖动会话顺序会改变共享的承载会话。
- 没有工作区的会话没有共享范围。
